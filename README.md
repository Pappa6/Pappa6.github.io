# Pappa6.github.io

## আজকের খরচ (Ajker Khoroch)

রোজ জানুন আজ কত টাকা নিশ্চিন্তে খরচ করা যায়। বাংলায়, লগইন ছাড়া।

অ্যাপ: https://pappa6.github.io/ajker-khoroch/

**গোপনীয়তা:** অ্যাপে কোনো সার্ভার বা ডেটাবেস নেই। ব্যবহারকারীর লেখা সব তথ্য শুধু তাঁর নিজের ফোনের ব্রাউজারে থাকে, কোথাও পাঠানো হয় না।

**Privacy:** The app has no server or database. Everything a user enters stays only in their own phone's browser and is never sent anywhere.
